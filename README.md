# Asignación Evaluada #1

Aplicación de escritorio realizada con JavaFX y FXML.

Desarrollador: Reynaldo Eliud Molina Torrez.

El programa contiene un menú principal y dos formularios:

- Registro de estudiantes.
- Registro de películas.

## Funciones principales

- Navegación desde el menú Catálogo.
- Menú contextual mediante clic derecho.
- Información del desarrollador mediante un Alert.
- Validación de campos vacíos.
- Registro de estudiantes en un TextArea.
- TableView con películas cargadas por defecto.
- Carga de los datos de una película al seleccionar una fila.

## Ejecutar el proyecto

En Windows, abrir una terminal dentro de la carpeta y ejecutar:

```powershell
.\mvnw.cmd javafx:run
```

También se puede abrir como proyecto Maven en IntelliJ IDEA y ejecutar la clase `AsignacionApplication`.
